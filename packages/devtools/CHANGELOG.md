# @bespokecore/devtools

## 0.1.0

### Minor Changes

- The first release (0.1.0): every package of the framework — the application kernel with constructor injection, the router, the
  page protocol and the React adapter, sessions, auth, the data layer, mail, queues, the scheduler, storage, live props, i18n, the
  devtools and OpenTelemetry — together with the meta package `bespokecore` and `create-bespoke-app`, all at one version. What changed
  for apps that followed the development waves is in UPGRADING.md ("Upgrading to 0.1.0").
